# Adversarial Search AI Lab

This repository contains an adversarial search lab implemented in a Jupyter Notebook:

- `CS3110_Games_2024BCS152PS_NLP.ipynb`

The notebook is designed as a hands-on AI lab focused on adversarial (game-playing) decision making.

## Likely topics covered

- Game-state representation for two-player settings
- Minimax / adversarial search reasoning
- Alpha-beta pruning ideas for efficient search
- Evaluating and comparing possible AI moves

## Run locally

1. Clone the repository:
   ```bash
   git clone https://github.com/SsemuliJoseph/Adverserial-Search-AI-Lab.git
   cd Adverserial-Search-AI-Lab
   ```
2. Ensure Python 3 is installed.
3. Install Jupyter (if needed):
   ```bash
   pip install notebook
   ```
4. Start Jupyter Notebook:
   ```bash
   jupyter notebook
   ```
5. Open `CS3110_Games_2024BCS152PS_NLP.ipynb` in your browser and run cells in order.
